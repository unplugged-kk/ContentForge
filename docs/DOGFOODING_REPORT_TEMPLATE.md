# ContentForge — Dogfooding Report Template

Copy this into `DOGFOODING_NOTES.md` at the repo root and fill it in as you go. **A rough note
written in the moment beats a tidy one written from memory.** Include a timestamp — the stack logs
correlate by time, and that is how a symptom becomes a cause.

Delete the sections you never use. Do not feel obliged to fill all of them; an empty section means
"nothing to report", which is itself useful.
